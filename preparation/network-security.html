📝 1️⃣ Caesar Cipher

INPUT: message (msg), shift (s)
PROCESS:
- Convert message to uppercase
- For each character in message:
    - Find its index in alphabet
    - Shift index by s (mod 26)
    - Append shifted character
OUTPUT: ciphered message
DECRYPT: repeat process with -s

📝 2️⃣ RSA Key Generation & Digital Signature

INPUT: primes p, q
PROCESS:
- Compute n = p * q
- Compute phi = (p-1)*(q-1)
- Find smallest e where gcd(e, phi) == 1
- Find d = modular inverse of e mod phi
KEYS: public (e, n), private (d, n)

SIGN:
- Compute signature S = m^d mod n
VERIFY:
- Compute verified_message = S^e mod n
OUTPUT: S, verified_message

📝 3️⃣ Playfair Cipher

INPUT: message (msg), key string (key)
PROCESS:
- Format key matrix (5x5 grid excluding J)
- Split message into pairs (add X if needed)
- For each pair:
    - Find positions in key matrix
    - Apply rules:
        - Same row → shift columns
        - Same column → shift rows
        - Else → swap columns
OUTPUT: ciphered message
DECRYPT: repeat with shift -1

📝 4️⃣ Hill Cipher (2x2 Matrix)

INPUT: message (msg), key matrix (2x2)
PROCESS:
- Split message into pairs (add X if needed)
- For each pair:
    - Convert letters to numbers
    - Multiply by key matrix mod 26
    - Convert back to letters
OUTPUT: ciphered message

DECRYPT:
- Compute determinant of key mod 26
- Find modular inverse of determinant
- Find adjoint matrix
- Compute inverse key matrix = adjoint * inverse(det) mod 26
- Repeat encryption using inverse key
OUTPUT: decrypted message

📝 5️⃣ Vigenère Cipher

INPUT: message (msg), key string (key)
PROCESS:
- For each letter:
    - Add corresponding key letter (mod 26)
OUTPUT: ciphered message

DECRYPT:
- For each letter:
    - Subtract corresponding key letter (mod 26)
OUTPUT: decrypted message

📝 6️⃣ Transposition Cipher (Rail Fence style)

INPUT: message (msg)
PROCESS:
- Split message into 2 lists: even & odd indices
- Concatenate lists → encrypted message
OUTPUT: ciphered message

DECRYPT:
- Split ciphered message into 2 halves
- Interleave characters from both halves
OUTPUT: decrypted message

📝 7️⃣ RSA-like Cipher on letter indices (this updated one)

INPUT: message (msg), primes p, q

KEY GENERATION:
- Compute n = p * q
- Compute phi = (p - 1) * (q - 1)
- Choose small e (e.g., e = 3)
- Find d = modular inverse of e modulo phi
- Public key = (e, n)
- Private key = (d, n)

ENCRYPTION (using private key):
- For each letter in message:
    - Convert letter to index (0-25)
    - Compute cipher_value = (index ^ d) mod n
OUTPUT: list of cipher values

DECRYPTION (using public key):
- For each cipher value:
    - Compute index = (cipher_value ^ e) mod n
    - Convert index back to letter
OUTPUT: decrypted message

📝 8️⃣ Diffie-Hellman Key Exchange

INPUT: prime p, base g
PROCESS:
- Alice picks private A, computes public a = g^A mod p
- Bob picks private B, computes public b = g^B mod p
- Alice computes shared key s1 = b^A mod p
- Bob computes shared key s2 = a^B mod p
OUTPUT: shared secret (s1 == s2)

🔑 Public Key and Private Key Concepts

Public Key Cryptography (Asymmetric Encryption)

  • Public Key: A key that is shared openly with everyone. It is used to encrypt data or verify a signature. This key is publicly distributed and anyone can use it to encrypt messages or verify signatures.

  • Private Key: A key that is kept secret and known only to the owner. It is used to decrypt messages or create a signature. The private key is kept secure and should never be shared.

  • Why use both?: Public key encryption solves the problem of key distribution in symmetric cryptography. You can use the public key to encrypt data, and only the recipient with the private key can decrypt it. Similarly, to prove the sender’s identity, the private key can be used to sign data, and anyone can verify the signature using the public key.

🔢 e, n, d, n in RSA and Related Concepts

In RSA Encryption:

  1. n (Modulus):

    • The product of two large prime numbers pp and qq.

    • n=p×qn = p \times q

    • nn is part of both the public and private keys. It defines the range of values (message values) that can be encrypted.

  2. e (Public Exponent):

    • A small integer, typically chosen as 3 or 65537.

    • e is part of the public key and is used for encryption.

    • ee should be coprime with ϕ(n)\phi(n), where ϕ(n)\phi(n) is the Euler’s Totient Function of nn and represents the number of integers that are coprime with nn.

  3. d (Private Exponent):

    • The private key exponent is used for decryption.

    • It satisfies the equation e×d≡1mod  ϕ(n)e \times d \equiv 1 \mod \phi(n), where ϕ(n)\phi(n) is Euler’s Totient Function of nn.

    • dd is calculated using the modular inverse of ee modulo ϕ(n)\phi(n).

Public Key: (e, n)
Private Key: (d, n)

🔢 Prime Numbers, Modular Arithmetic, and GCD

Prime Numbers:

  • A prime number is a natural number greater than 1 that has no positive divisors other than 1 and itself.

  • Example: 2, 3, 5, 7, 11, 13, etc.

Greatest Common Divisor (GCD):

  • GCD of two numbers is the largest integer that divides both numbers without leaving a remainder.

  • Example: gcd(12,15)=3\text{gcd}(12, 15) = 3 because 3 is the largest number that divides both 12 and 15.

  • Euclidean Algorithm: A method for calculating the GCD of two integers aa and bb:

    1. Divide aa by bb, and get the remainder rr.

    2. Replace aa with bb and bb with rr, repeat until r=0r = 0.

    3. The last non-zero remainder is the GCD.

Modular Arithmetic:

  • Modular Arithmetic is a system of arithmetic for integers, where numbers “wrap around” after reaching a certain value (the modulus).

  • In RSA, we often compute values modulo nn, which is why we use expressions like amod  na \mod n.

  • Example: 5mod  3=25 \mod 3 = 2, because when 5 is divided by 3, the remainder is 2.

Modular Inverse:

  • The modular inverse of an integer aa modulo mm is the integer xx such that:

    a×x≡1mod  ma \times x \equiv 1 \mod m

  • The modular inverse exists only if aa and mm are coprime (i.e., gcd(a,m)=1\text{gcd}(a, m) = 1).

  • Euclidean Algorithm can be used to find the modular inverse.

🧩 Encryption and Decryption in Algorithms

Hill Cipher (Matrix-Based):

  • Uses a 2x2 matrix and works on pairs of letters.

  • Encryption: The plaintext letter pair is multiplied by the key matrix and reduced modulo 26 to get the ciphertext.

  • Decryption: The ciphertext is decrypted by multiplying it with the modular inverse of the key matrix (using the determinant and adjoint).

RSA (Public-Key Encryption):

  • Encryption: The sender uses the receiver’s public key (e, n) to encrypt a message.

    C=Memod  nC = M^e \mod n

  • Decryption: The receiver uses their private key (d, n) to decrypt the message.

    M=Cdmod  nM = C^d \mod n

Diffie-Hellman Key Exchange:

  • Key Exchange: Two parties (Alice and Bob) exchange public values, and each calculates the shared secret using their private key and the other party’s public value.

🛡️ Algorithms Using GCD, Modular Inverse, etc.

DSS (Digital Signature Algorithm):

  • A digital signature is used to verify the authenticity of a message or document.

  • It involves signing the message with a private key and verifying it with the public key.

  • Similar to RSA but focuses on hash functions and signing/verification.

Diffie-Hellman:

  • Used for securely exchanging cryptographic keys over a public channel.

  • Involves the use of modular exponentiation and relies on the difficulty of the discrete logarithm problem.

Elliptic Curve Cryptography (ECC):

  • Uses elliptic curves instead of prime numbers for encryption.

  • Offers the same security as RSA with much smaller key sizes, making it more efficient.

🔑 Practical Applications

  1. RSA: Secure communication in email encryption, web browsing (HTTPS), and digital signatures.

  2. Diffie-Hellman: Key exchange in VPNs, secure messaging apps like WhatsApp, and SSH.

  3. Hill Cipher: Educational purposes, as it’s easy to implement with matrices and provides insights into linear algebra.

  4. DSS: Used in blockchain, digital signatures, and authentication.
