📊 Memo Load Calculator

📘 How to Use the Memo Load Calculator

1. Enter the number of Centers involved in your memo system.
2. Enter the number of Blocks per Center that are being managed.
3. The calculator will automatically update the total reads, writes, and deletes based on average values for each block.
4. You'll see a breakdown of the data load in terms of daily, weekly, and monthly totals.
5. Adjust the number of centers or blocks, and the system will instantly update the results.

🔧 How It Works

The Memo Load Calculator calculates the total data load for your memo system based on the following factors:
1. Centers: The number of centers handling memo data.
2. Blocks per Center: The number of blocks in each center.
3. Average Reads, Writes, and Deletes per Block: These values are based on the memo system’s operations per block.
4. Document Size: Each memo document size is set at 1503 bytes. This is used to calculate the data size for reads and writes.
The system multiplies these values together to determine the total reads, writes, and deletes for daily, weekly, and monthly time frames.
Data Sizes are calculated by multiplying the number of reads/writes by the document size and converting the total bytes into megabytes (MB).
